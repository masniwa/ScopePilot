# ScopePilot Fork 0.13.0

gsgwr/ScopePilotをFork元とする派生版です。原版はumberbyte/ScopePilotです。原版のBSD-3-Clauseライセンスと著作権表記を保持します。

## 変更点

- 明示的に許可したAIの通常UI操作で非GETのHTTP要求を収集します。禁止操作は全探索フェーズで照合します。
- 反復通信とリダイレクトの記録を補強し、Edge NetLogと照合します。要求の送信と応答本文の保存状態を区別します。
- 操作候補・未実行操作を保持し、進展に応じて点検します。特殊操作は手動一覧へ引き継ぎます。
- 複数資料（最大20件・合計250,000文字）、SPA認証、URL入力欄の自動送信制御を改善します。
- 表示名をScopePilot Fork、版を0.13.0に変更します。Fork専用のインストール先、登録ID、ショートカット、起動中判定を使用します。

## 互換性と制限

内部実行ファイルはScopePilot.exe、プロジェクトファイルは既存の.scopepilot.json形式です。既存案件は起動時にフォルダーを選択して開けます。アプリ共通設定とBurp JAR既定位置は元版と共通です。同じ案件の同時編集は避けてください。

AIによる未知サイトの全機能発見、全操作の自動実行、応答本文の完全取得は保証しません。OTP、認証情報変更、OSダイアログ等は手動引き継ぎの対象です。Service Worker / WebSocket必須の機能はAI入力・送信モードの対応範囲外です。詳細はREADMEの制限を参照してください。

コード署名はありません。配布ZIP / Setup.exeとSHA-256を併せて提供します。

## 検証範囲

Windows x64で全回帰271件が合格し、失敗・スキップは0件です。実ZAP連携4件と、実Edgeのローカルfixtureによる通信・禁止操作の検証を含みます。表示変更後のWPF関連14件も合格しています。これらは実サイト全体の網羅率を示す値ではありません。

ARM64配布物はx64環境でのクロスビルドとCPU形式・ライセンスの検査対象です。ARM64実機での起動・外部ツール連携は別途確認してください。
